📘 How It Works & Academic Notes

  • href Attribute: Hypertext Reference specifying target URL, file path, or hash identifier.
  • Security Best Practice: Links using target="_blank" must include rel="noopener noreferrer" to prevent reverse tab-napping and unauthorized access to window.opener.
  • Relative Traversal: ../ navigates one level up in the folder tree, while ./ refers to the current working directory.
