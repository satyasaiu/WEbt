Experiment 10 • HTML5 Graphics & Vector Art

HTML5 Canvas Graphics & Inline SVG

Comparing immediate-mode pixel rendering via the HTML5 <canvas> 2D API against retained-mode vector rendering using inline Scalable Vector Graphics (<svg>).

⚡ Live Interactive Demonstration

1. HTML5 2D Canvas (Draw with mouse)
Immediate-mode bitmap rasterization via canvas.getContext('2d').
2. Inline Scalable Vector Graphics (<svg>)
Retained-mode XML vector nodes accessible directly within the DOM.

📘 How It Works & Academic Notes

  • Canvas (Raster Graphics): Pixel-based rendering ideal for high-performance games, photo filters, and charts with thousands of dynamic objects. Does not retain DOM event listeners on individual shapes.
  • SVG (Vector Graphics): Resolution-independent XML geometry. Shapes scale infinitely without pixelation and can be styled with CSS and manipulated via DOM event listeners.
