📘 How It Works & Academic Notes

  • Structural Tags: <thead> groups header rows, <tbody> contains the core records, and <tfoot> contains summary rows. This allows tables to scroll independently or repeat headers across printed pages.
  • Cell Spanning: colspan="n" expands a cell horizontally across n columns, while rowspan="n" expands a cell vertically down across n rows.
  • Accessibility: <th> denotes header cells, paired with <caption> to provide context for screen-reader users.
