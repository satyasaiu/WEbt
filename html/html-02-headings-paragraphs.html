Headings, Paragraphs & Text Formatting

Exploring HTML semantic heading levels (H1 through H6), paragraph block tags, horizontal thematic breaks, line breaks, and inline text formatting tags.

⚡ Live Interactive Demonstration

1. Semantic Heading Hierarchy (H1 – H6)

Heading Level 1 (<h1>) — Primary Page Heading

Heading Level 2 (<h2>) — Major Section Heading

Heading Level 3 (<h3>) — Sub-section Topic

Heading Level 4 (<h4>) — Minor Heading

Heading Level 5 (<h5>) — Small Category Header
Heading Level 6 (<h6>) — Fine Detail Header

2. Paragraphs & Inline Formatting Elements

This paragraph demonstrates standard text layout. HTML provides specific semantic tags to emphasize words: Strong importance (<strong>), Emphasized tone (<em>), Highlighted text (<mark>), Deleted / Strikethrough text (<del>), Inserted / Underlined text (<ins>), and Inline code (<code>).

Scientific & Mathematical notations rely on subscript and superscript:
Chemical Formula of Water: H2O (using <sub>)
Pythagorean Theorem: a2 + b2 = c2 (using <sup>)

📘 How It Works & Academic Notes

  • Heading Hierarchy: An HTML page must ideally have exactly one <h1> representing the document's main subject, followed by descending levels (<h2> down to <h6>) without skipping ranks.
  • Paragraphs: <p> tags are block-level elements that automatically insert vertical spacing before and after the text.
  • Semantics vs Presentation: <strong> and <em> convey meaning to assistive technologies (screen readers change voice inflection), whereas older tags like <b> and <i> are purely stylistic.
