📘 How It Works & Academic Notes

  • getElementById vs querySelector: getElementById offers fastest lookups for ID tokens. querySelector uses CSS selector syntax, matching the first occurrence of any arbitrary selector.
  • NodeList Iteration: querySelectorAll returns a static NodeList which can be iterated using forEach().
  • textContent vs innerHTML: Use textContent for plain strings to prevent Cross-Site Scripting (XSS). Use innerHTML only when purposely rendering HTML element tags.
