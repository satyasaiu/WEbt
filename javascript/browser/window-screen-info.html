📘 How It Works & Academic Notes

  • BOM Hierarchy: The window object represents the top-level global environment in client-side JavaScript. Both document and screen are child properties of window.
  • innerWidth vs outerWidth: innerWidth measures the content viewport excluding browser title bars, window borders, and developer tools. outerWidth measures the physical outer application window.
