Glassmorphic Non-Blocking Modal

Unlike native alert(), this custom dialog does not freeze the JavaScript event loop or block background timer executions.

📘 How It Works & Academic Notes

  • Blocking vs Non-Blocking: Native dialogs (alert, confirm, prompt) are synchronous and freeze the browser execution thread until dismissed. Modern web applications favor custom non-blocking DOM modal dialogs.
  • Event Loop & Timers: setTimeout(fn, ms) places the callback into the Web API task queue to run once after the specified delay. setInterval(fn, ms) runs recurrently until clearInterval(id) is invoked.
