Architectural Comparison: localStorage vs sessionStorage
localStorage:
  • Persists across tab closures & browser restarts.
  • Shared across all tabs belonging to the same origin.
  • Capacity: ~5MB to 10MB per origin.
sessionStorage:
  • Cleared automatically when tab or window is closed.
  • Isolated strictly to the individual browser tab context.
  • Ideal for single-session transactions & wizard state.

📘 How It Works & Academic Notes

  • Tab Scoping: Opening the same URL in a new browser tab generates a fresh, independent sessionStorage container without sharing data from the first tab.
  • Survivability: sessionStorage gracefully survives page refreshes and URL hash changes within the identical tab session.
