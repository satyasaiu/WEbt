📘 How It Works & Academic Notes

  • Cart Serialization: Cart items are mapped to objects: { id, title, price, quantity }, serialized into JSON, and persisted under key 'weblab_cart'.
  • Quantity Aggregation: Adding an already present item increments its quantity rather than appending duplicate rows.
  • Cross-Tab Sync: Listening to the window.addEventListener('storage', ...) event allows other open tabs of the same website to update their cart counter simultaneously in real time.
