Experiment 24 • Client State Persistence

User Preferences & Theme Persistence

Saving user customization preferences (accent glow color, font scale, UI density) persistently into browser localStorage so settings survive across sessions and page reloads.

⚡ Live Interactive Demonstration

Customized Preference Sandbox

Accent Theme Active

This component immediately reflects your chosen visual preferences. Changing any setting automatically updates localStorage and updates this document state in real-time.

📘 How It Works & Academic Notes

  • Preference Architecture: Encapsulates all user choices into a unified JSON object: { accent: '#22d3ee', fontSize: '16px', density: '2rem' }.
  • Storage Hook: Checks localStorage.getItem('weblab_user_prefs') on page load (DOMContentLoaded) and applies properties before rendering occurs to prevent flash of unstyled content (FOUC).
