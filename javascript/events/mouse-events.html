📘 How It Works & Academic Notes

  • Event Coordinates: e.clientX / Y provides coordinates relative to the viewport, while e.offsetX / Y measures offset relative to the targeted container padding edge.
  • preventDefault(): Intercepting contextmenu and invoking e.preventDefault() cancels the native OS browser context menu, enabling custom context popup menus.
  • mouseenter vs mouseover: mouseenter does not bubble when transitioning between child nodes, whereas mouseover bubbles up the DOM tree hierarchy.
