📘 How It Works & Academic Notes

  • Event Bubbling (Default Phase): When an event triggers on an element, the browser executes handlers on the innermost target first, then propagates up through each successive parent node to document and window.
  • event.stopPropagation(): Prevents further propagation of the current event along the dispatch chain, halting parent listeners from executing.
  • Event Delegation: By attaching a single listener to a common ancestor, you can handle events for hundreds of present and future dynamic child nodes via e.target, dramatically optimizing memory usage.
