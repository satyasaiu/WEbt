📘 How It Works & Academic Notes

  • input vs change: The input event fires synchronously each time the value changes (every keystroke, paste, or cut). The change event fires only when the change is committed (e.g. upon losing focus with blur or selecting a dropdown option).
  • focus & blur: focus triggers when an element gains keyboard or mouse focus; blur triggers when focus leaves the element. These events do not bubble.
