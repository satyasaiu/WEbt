Document Structure Nodes
<!DOCTYPE html>

The Document Type Declaration instructs modern web rendering engines to render the page in standard compliance mode rather than quirks mode. It is the very first instruction in every HTML5 file.

<!DOCTYPE html>

📘 How It Works & Academic Notes

  • DOCTYPE: Tells the web browser to treat this document under the HTML5 standard specifications.
  • Character Encoding (UTF-8): <meta charset="UTF-8"> ensures all symbols, emojis, and global language characters display accurately without corruption.
  • Responsive Viewport: <meta name="viewport" content="width=device-width, initial-scale=1.0"> matches document width to physical device screen width and sets initial zoom level.
  • Separation of Concerns: The <head> container houses document directives, titles, external style links, and scripts, while the <body> houses all visible user interface content.
