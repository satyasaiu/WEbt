Experiment 08 • Semantic Architecture

Semantic HTML5 Layout Elements

Demonstrating structural layout tags introduced in HTML5 that convey meaning to browsers, search engines, and assistive screen readers without relying on generic non-semantic <div> soup.

⚡ Live Interactive Demonstration

Interactive Visual Blueprint of a Semantic Webpage:
<header> & <nav>

Contains brand identity, logo, introductory heading, and primary site navigation links.

<main>

Encloses the unique, central content of the document. Only one <main> per page.

<section>

A thematic grouping of content, typically with its own heading.

<article>

A standalone, self-contained composition (e.g. blog post, news story, product card) that makes sense independently.

<aside>

Secondary or indirectly related information such as author biography, sidebars, related links, or advertising.

<footer>

Houses copyright notices, authorship credits, student registration number, terms of service, and back-to-top links.

📘 How It Works & Academic Notes

  • Accessibility (ARIA Landmarks): HTML5 semantic tags automatically map to ARIA landmark roles, enabling users with assistive technologies to skip directly to navigation or main content.
  • SEO Optimization: Search engine web crawlers prioritize content inside <main> and <article> over repetitive header and footer content.
  • Div vs Semantic Tags: Reserve <div> exclusively as a styling hook when no semantic element naturally describes the content.
