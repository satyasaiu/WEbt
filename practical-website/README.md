## Project Description
This repository contains a complete, professional, responsive, and interactive practical web application developed for college laboratory assignment submission. The application is designed as a self-contained laboratory portal presenting **45 fully functional experiments** organized across HTML, CSS, and JavaScript. 

The entire user interface is engineered using a modern **Glassmorphism Design System** featuring deep gradient background layers, translucent frosted glass cards (`backdrop-filter: blur(20px)`), glowing border accents, smooth hover animations, and real-time vanilla JavaScript client-side filtering.

---

## Technologies Used
- **HTML5:** Semantic architecture, DOCTYPE declarations, media elements, forms, canvas API, and SVG vector graphics.
- **CSS3:** Glassmorphism design system, CSS custom properties (variables), Flexbox 1D layouts, CSS Grid 2D matrices, 2D/3D transforms, keyframe animations, and mobile-first responsive media queries.
- **JavaScript (ES6+):** Pure Vanilla JavaScript without external dependencies (no React, jQuery, or Bootstrap required).
- **DOM APIs:** Dynamic node creation, classList manipulation, querySelector, and event delegation.
- **Browser Object Model (BOM):** Window, Screen, Location, History, Navigator, and asynchronous timing loops.
- **Web Storage APIs:** `localStorage` and `sessionStorage` state persistence, serialization, and cross-tab storage events.

## Key Features
1. **Interactive Demonstrations:** Every single experiment includes a working, tactile demonstration (e.g. calculator performs arithmetic calculations, clock shows real-time system clock, stopwatch records laps, form validation tests regex).
2. **Glassmorphism Design System:** Consistent translucent card containers, backdrop filters, soft gradients, glowing highlights, and mobile-adaptive layouts.
3. **No External Dependencies:** 100% offline-ready. Built with pure web standards without relying on external CDNs or remote APIs.
4. **Seamless Navigation:** Every page provides breadcrumbs, navigation to Home, category listing links, and direct previous/next experiment transitions with zero broken relative paths.
5. **Real-time Client-Side Search:** Listing pages feature dynamic keyword filtering allowing instantaneous searching by experiment number, title, or description.
6. **Academic Documentation:** Each page features an interactive "How It Works & Academic Notes" section explaining the underlying web engineering concepts.

## How to Run the Website
1. **Direct Browser Execution (No Server Required):**
   - Double-click `index.html` in your file manager or drag it into any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).
2. **Local HTTP Server (Optional):**
   ```bash
   # Using Python 3 built-in server:
   python -m http.server 8080
   
   # Or using Node.js http-server:
   npx http-server .
   ```
   Open `http://localhost:8080` in your web browser.
3. **Navigation Flow:**
   - From the main dashboard (`index.html`), click on any category card (**HTML Programs**, **CSS Programs**, or **JavaScript Programs**).
   - Filter or select any experiment to open its live interactive laboratory demonstration.
