Interactive Task Manager (To-Do App)

A productivity task organizer featuring task creation, completion toggles, active/completed filters, live statistics, and persistent synchronization with browser localStorage.

📘 How It Works & Academic Notes

  • Data Model: Each task is represented as an object: { id: timestamp, title: string, completed: boolean }.
  • Array Methods: Operates using functional array techniques: filter(), map(), and find() to maintain immutable state transitions.
  • LocalStorage Synchronization: Calls localStorage.setItem('weblab_tasks', JSON.stringify(tasks)) on any modification, ensuring data remains intact upon page refresh.
