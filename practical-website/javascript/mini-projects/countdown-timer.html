Customizable Countdown Timer

An interactive countdown timer with SVG circular progress meter, presets (1m, 5m, 10m), pause/resume mechanics, and audio-visual completion notifications.

⚡ Live Interactive Demonstration

01:00

📘 How It Works & Academic Notes

  • SVG Stroke Dashoffset: A circle with radius r=90 has a circumference \(2\pi r \approx 565.48\). As time elapses, stroke-dashoffset scales proportionally from 0 to 565 to visually drain the ring.
  • Synthesized Completion Chime: When timer reaches 0, the Web Audio API synthesizes a pleasant dual-tone chime (587Hz → 880Hz) without relying on external MP3 audio files.
  • Stateful Resumption: Pausing stores the exact seconds remaining, allowing seamless continuation upon unpausing.
