Implementing the ISO/IEC 7812 Luhn checksum algorithm (Mod 10), automated IIN issuer identification (Visa, Mastercard, Amex), and input masking using simulated dummy test data.

📘 How It Works & Academic Notes

  • Luhn Algorithm (Mod 10): Starting from the rightmost check digit, double every second digit. If doubling results in a number > 9, subtract 9 (or add digits). Sum all values; the number is valid if and only if sum % 10 === 0.
  • IIN Prefix Detection: Cards starting with 4 are Visa; 51-55 or 22-27 are Mastercard; 34/37 are American Express.
