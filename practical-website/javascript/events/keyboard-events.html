📘 How It Works & Academic Notes

  • key vs code: e.key represents the printed character produced (taking Shift and CapsLock into account). e.code identifies the physical key location on the keyboard hardware regardless of active language layouts.
  • Modifier Flags: Boolean properties e.shiftKey, e.ctrlKey, e.altKey, and e.metaKey register key combination shortcuts (such as Ctrl+S or Alt+Tab).
  • Deprecation Notice: e.keyCode is deprecated in the official W3C DOM Level 3 Events specification in favor of the standard e.key.
