📘 How It Works & Academic Notes

  • window.location: Provides complete introspection of the document's URL. Assigning a new value to location.href navigates to a new webpage.
  • History API (pushState): history.pushState(state, title, url) adds an entry to the browser's session history stack, permitting Single Page Applications (SPAs) to update URLs without reloading.
  • popstate Event: Listens to browser forward/back button clicks when navigating through pushState session history.
