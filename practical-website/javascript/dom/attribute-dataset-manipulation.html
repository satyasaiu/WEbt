📘 How It Works & Academic Notes

  • Dataset API: Any attribute beginning with data- is mapped to the element's dataset property. Hyphenated names become camelCase (e.g. data-student-id → element.dataset.studentId).
  • getAttribute & setAttribute: Standard methods for reading and writing any generic HTML attribute token.
  • removeAttribute: Deletes an attribute entirely from the element node rather than merely setting its value to null or an empty string.
