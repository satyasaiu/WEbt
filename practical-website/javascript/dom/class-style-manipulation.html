📘 How It Works & Academic Notes

  • classList API: Clean modern interface replacing clumsy string manipulation of className. Provides add(), remove(), toggle(), and contains().
  • element.style vs Stylesheet: Writing to element.style.color = '#fff' injects inline CSS with specificity (1,0,0,0), overriding rules declared in external stylesheets.
  • CamelCase Property Naming: CSS hyphenated properties become camelCased in JavaScript (e.g. background-color becomes style.backgroundColor).
