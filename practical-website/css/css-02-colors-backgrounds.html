Experiment 02 • Visual Styling

Colors, Gradients & Background Styling

Demonstrating modern CSS color spaces (HEX, RGB/RGBA, HSL/HSLA), linear and radial gradients, dynamic gradient angle manipulation, and backdrop filters.

⚡ Live Interactive Demonstration

Dynamic CSS Background Output
background: linear-gradient(135deg, #38bdf8, #a855f7);

📘 How It Works & Academic Notes

  • Color Representations:
    • HEX: #38bdf8 (Hexadecimal red, green, blue values from 00 to FF).
    • RGBA: rgba(56, 189, 248, 0.8) includes alpha opacity from 0.0 (transparent) to 1.0 (opaque).
    • HSL: hsl(199, 95%, 60%) defines hue angle (0–360°), saturation (%), and lightness (%).
  • Linear vs Radial Gradients: Linear gradients transition along a straight directional vector (degrees or keywords like to bottom right), while radial gradients emanate outward from a central circular or elliptical focal point.
