📘 How It Works & Academic Notes

  • Specificity Weight: Represented as a 4-part tuple (a, b, c, d):
    • a: Inline styles (e.g. style="...") = 1,0,0,0
    • b: ID selectors (e.g. #specialItem) = 0,1,0,0
    • c: Classes, attributes, and pseudo-classes (e.g. .card, [data-role], :hover) = 0,0,1,0
    • d: Type/element and pseudo-elements (e.g. p, div, ::before) = 0,0,0,1
  • The Cascade Order: When two competing rules target the same element with identical specificity, the rule written last in the stylesheet source wins.
