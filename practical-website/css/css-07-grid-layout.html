📘 How It Works & Academic Notes

  • Two-Dimensional Grid: Unlike Flexbox (which handles rows or columns individually), CSS Grid aligns items along both rows and columns simultaneously.
  • Fractional Unit (fr): Represents a fraction of the available space inside the grid container after fixed tracks and gaps are subtracted.
  • auto-fit & minmax: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)) achieves complete responsive card reflow without writing explicit media queries.
