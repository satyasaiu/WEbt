📘 How It Works & Academic Notes

  • One-Dimensional Layout: Flexbox deals with items in one dimension at a time — either as a row or as a column.
  • Main Axis vs Cross Axis: When flex-direction: row, the main axis is horizontal and the cross axis is vertical. Switching to column inverts these axes.
  • justify-content vs align-items: justify-content controls item alignment along the main axis, whereas align-items controls alignment along the cross axis.
